> [!WARNING]
>
> ### Реакция антивируса
>
> Для работы zapret требуется WinDivert — инструмент перехвата и фильтрации трафика. Антивирус может отреагировать на него, поскольку такой инструмент способен использоваться как добросовестными, так и вредоносными программами, хотя сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их и отправляют в карантин. Название такого обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр `Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда`. Если вы уверенно настраиваете исключения, предпочтительно добавить каталог в исключения; при недостаточном понимании настроек рекомендуется отключить детектирование PUA.

## ⚙️ Использование

1. Сначала включите Secure DNS.
   * В Chrome активируйте `Использовать безопасный DNS` и выберите поставщика, отличного от `Поставщик по умолчанию`.
   * В Firefox включите `DNS через HTTPS`, установите режим `Персональный`, выберите `Выбрать провайдера/поставщика` и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS в настройках самой ОС. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
   * На роутерах Keenetic включите параметр `Транзит запросов`. При его отключении Secure DNS на компьютере может работать некорректно.

2. Откройте [страницу последнего релиза](https://github.com/silentassassinplaza/zapret-discord-youtube/releases/latest) и скачайте ZIP- или RAR-архив.

3. Откройте свойства архива и включите `Разблокировать`. Владельцы 7-Zip или PeaZip могут пропустить этот шаг.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
   * Чтобы подобрать рабочую стратегию, откройте **`service.bat`** и последовательно выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для установки выбранной стратегии в автозапуск перейдите в **`service.bat`** -> `Install Service` -> выберите стратегию.

## ℹ️ Файлы и их назначение

- [**`general.bat ...`**](./general.bat) запускает стратегию непосредственно.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** — настройка обхода сервисов из `ipset-all.txt`.  
  Этот режим полезен при диагностике ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается состояние:
    - `none` — проверка не применяется ни к одному IP;
    - `loaded` — IP сопоставляются со списком;
    - `any` — фильтр применяется к любому IP.
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений.
  - **`Replace active fakes`** — замена используемого fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — получение актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts-файла <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — ручная проверка обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После `general*` ничего не происходит

При запуске стратегии отдельным BAT-файлом, а не через `service`, должен появиться `winws.exe`, который виден на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

  `netsh winsock reset`

  `netsh int ip reset all`

  `netsh winhttp reset proxy`

  `ipconfig /flushdns`

- Перезагрузите компьютер.

### Веб-версия Telegram не подключается

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts-файл устарел, программа предложит обновить его вручную:  
- скопируйте весь текст из открывшегося блокнота;
- откройте текстовым редактором от имени администратора файл `hosts` в появившемся каталоге;
- вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки;
- сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Когда это не помогает, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/silentassassinplaza/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии способны со временем терять работоспособность.**
> Вариант, который работал раньше, может перестать работать после обнаружения. В репозитории собраны разные стратегии; если готовые варианты не подходят, создайте новую на основе одной из них и измените параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.
- Убедитесь, что нужный адрес присутствует в списках доменов или IP.
- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительные сведения есть в [#765](https://github.com/silentassassinplaza/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте `Y`.
- Удалите каталог zapret.
- Скачайте свежую версию [`zapret-discord-youtube-...`](https://github.com/silentassassinplaza/zapret-discord-youtube/releases).
- Откройте свойства архива правой кнопкой мыши. Если внизу есть `Разблокировать`, установите флажок, нажмите `Применить`, затем `ОК`.
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция по этому случаю: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows, открытой через Win+R -> `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежний вариант перестал работать, последовательно испытайте остальные стратегии.
- См. также [#251](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если браузерная версия также недоступна, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительно: [#252](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/silentassassinplaza/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Игры не работают

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не решит проблему, дополнительно включите `ipset any`.

Учтите: `ipset any` может нарушить открытие большого числа сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/silentassassinplaza/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблема не описана

- Сообщите о ней [здесь](https://github.com/silentassassinplaza/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Включить дополнительные ресурсы в обход можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
